# Zhas Aru ZR — сайт

Қазақстан бойынша 7 филиалы бар сұлулық салоны және косметологтарға арналған
авторлық оқу курсы («ОҚУ КУРСЫ») үшін жасалған көп беттік сайт. Қазақша/орысша
екі тілде, mobile-first.

## Құрылым

- `index.html` — Алматы филиалының толық жұмыс істейтін басты беті (барлық
  бөлімдер: hero, филиалдар, біз туралы, қызметтер, оқу курсы, шеберлер,
  пікірлер, сертификаттар, галерея, байланыс).
- `branches/*.html` — қалған 6 филиал (Астана, Өскемен, Шымкент, Ақтау,
  Атырау, Ақтөбе) үшін «жақында ашылады» үлгідегі беттер. `index.html`-дан
  автоматты түрде генерацияланады.
- `assets/css/style.css` — дизайн-жүйе (түс токендары, типографика, барлық
  компоненттер).
- `assets/js/main.js` — мобильді мәзір, тіл ауыстыру, scroll-reveal
  анимациялар, hero видео/дыбыс логикасы, шексіз каруселдер, FAQ, форма.
- `assets/js/translations.js` — ҚАЗ/РУС аударма сөздігі.
- `assets/img/`, `assets/video/` — сайтта қолданылатын оптималданған
  медиа (уақытша/placeholder материалдар — нақты фото/видеоларға ауыстыру
  керек).
- `serve.mjs` — локальді dev-сервер (`node serve.mjs` → `http://localhost:3000`).
- `screenshot.mjs` — Puppeteer скриншот құралы
  (`node screenshot.mjs http://localhost:3000 <label> [--mobile]`).
- `build-cities.mjs` — `index.html`-ды үлгі ретінде алып, қалған 6 филиал
  бетін қайта генерациялайды (`node build-cities.mjs`). Жаңа қала қосу немесе
  ортақ бөлімдерді (қызметтер, курс, шеберлер, пікірлер) өзгерту кезінде
  осыны қайта жүргізіңіз.

## Локальді іске қосу

```bash
npm install
node serve.mjs
# http://localhost:3000
```

## Белгілі шектеулер / келесі қадамдар

- **CRM интеграциясы жоқ.** Форма (`#course-lead-form`, `#contact-form`)
  қазір тек клиент жағында «қабылданды» деп көрсетеді. `assets/js/main.js`
  ішінде `TODO(integration)` белгісі бар жерге Twenty CRM webhook
  эндпойнтін қосу керек.
- Галерея/видео-пікірлер бөлімдеріндегі видеолар — алдын ала іріктелген
  placeholder материалдар. Нақты before/after жұптарын қолмен реттеу керек.
- Аудио-пікірлер интерфейсі дайын, бірақ нақты аудио файлдар жоқ.
- Астана/Өскемен/Шымкент/Ақтау/Атырау/Ақтөбе беттері — толықтай үлгі
  (мекенжай, карта, фото әлі жоқ). Нақты деректер түскен сайын
  `branches/*.html`-ды жеке өңдеуге немесе `build-cities.mjs` скриптін
  толықтыруға болады.
